# mi-portafolio-Erick-Estrada

- Se corrigieron las sugerencias de la ia las cuales fueron
Jerarquía incorrecta de encabezados

Utilicé un <h1> y luego pasé directamente a <h3>, omitiendo el nivel <h2>.

❌ Párrafos dentro de encabezados

Coloqué etiquetas <p> dentro de <h3>, lo cual no es una estructura válida en HTML.

❌ Uso inadecuado de <article>

Utilicé etiquetas <article> para contenido que no era independiente ni autónomo.

❌ IDs con espacios

Definí identificadores como id="sobre mi" e id="mis metas", lo que puede causar problemas al referenciarlos desde CSS, JavaScript o enlaces internos.

❌ Uso excesivo de etiquetas <br>

Empleé <br> para crear separación visual entre secciones en lugar de utilizar CSS para el espaciado.

❌ Etiqueta <nav> sin enlaces reales

El elemento de navegación solo contenía texto de referencia y no enlaces funcionales.

❌ Comentario HTML mal escrito

Un comentario no tenía la sintaxis correcta (<!-- comentario -->), lo que puede generar errores de interpretación.

❌ Sección sin encabezado

La sección de habilidades no incluía un título mediante una etiqueta de encabezado (<h2>).

❌ Contenido fuera de <main>

Un párrafo relacionado con las metas estaba ubicado fuera del contenido principal de la página.

❌ Footer fuera del <body>

La etiqueta <footer> estaba colocada después del cierre de <body>, lo que hace que la estructura HTML sea inválida.

❌ Problemas de apertura y cierre de etiquetas

Algunas etiquetas como <section> y <article> estaban abiertas o cerradas en posiciones incorrectas, afectando la estructura del documento.
